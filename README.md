# m5-intercom-recorder

バイク用 Bluetooth インカムで話した会話を、M5Stack Core2 で microSD カードに録音するレコーダーです。B+COM 対応。

- スマホを使わずに、インカムの会話を録音できます。
- 声だけを小さなファイルで残せるので、長いツーリングでも丸ごと録れます（1 時間で約 6〜9MB）。
- 出発前に、二人の声の大きさをレベルメーターで見比べられます。

B+COM の「アクションカメラ録音」と同じつなぎ方で、カメラの代わりに Core2 をつなぎます。

## 必要なもの

- M5Stack Core2
- microSD カード（FAT32。32GB 以下のカードならそのまま使えます）
- B+COM（動作を確かめたのは SB6XR V1.3）
- バイクの USB 給電（内蔵電池で録れるのは 2〜3 時間ほどなので、長く走る日は給電をおすすめします）

## 書き込み

### ビルドせずに書き込む

1. [リリース](https://github.com/daig0rian/m5-intercom-recorder/releases)から `m5-intercom-recorder-vX.Y.Z.bin` をダウンロードします。
2. Core2 を USB で PC につなぎ、Chrome か Edge で [ESP Launchpad](https://espressif.github.io/esp-launchpad/) を開きます。
3. 「DIY」で、ダウンロードしたファイルを `0x0` の場所に書き込みます。

新しい版にするときは、`-update.bin` で終わるファイルを `0x10000` の場所に書き込むと、設定とペアリングが残ります（`0x0` に書くと、どちらも消えます）。

Python の esptool を使うなら、`python -m esptool --chip esp32 write_flash 0x0 m5-intercom-recorder-vX.Y.Z.bin` でも書き込めます。

### ビルドして書き込む

ESP-IDF v5.5 系（v5.5.6 で確認）でビルドして、Core2 に書き込みます。

```
idf.py build
idf.py -p PORT flash
```

`PORT` は Core2 をつないだシリアルポートです（Windows なら `COM3` など）。必要な部品はビルドのときに自動で取得されます。

## 使い方

### はじめに一度だけ: B+COM とペアリングする

1. B+COM の B2 ボタンを長押しして、待機状態にします。
2. Core2 の「機器検索」を押すと、見つかった機器が並びます。B+COM の行を押します（SB6XR は「B6R Universal」という名前で出ます）。
3. B+COM から「B+COM2接続」と聞こえたら完了です。

B+COM アプリの「ユニバーサルインターコール」は、オフ（初期設定）のままにしてください。

### ツーリングの日

1. B+LINK で、二人の通話をつなぎます。
2. Core2 の電源を入れると、いつもの B+COM に自分でつなぎに行きます。画面の上に「音声 mSBC 16kHz」と出れば、声が届いています。
3. 一人ずつ話してもらい、レベルメーターの振れ方を見比べます。差が大きいときは、声の小さい人がマイクを口元に寄せるか、B+COM のスマホアプリでマイク音量を上げます。
4. 「録音」を押して出発します。電源ボタンを短く押すと画面が消え、電池が長持ちします。
5. 着いたら「停止」を押します。

Core2 を持つ人は、列の先頭か最後尾を走ると通信が安定します（B+COM のアクションカメラ録音と同じおすすめです）。

### 帰ってから

SD カードの `REC` フォルダに、録音した日時の名前（`20261120_103000.opus` など）で保存されています。VLC などで再生できます。動画編集ソフトには `.opus` を読めないものがあります。そのときは、WAV に変換してから読み込んでください（例: `ffmpeg -i 20261120_103000.opus 20261120_103000.wav`）。

## 安心して録るために

何もしなくても、録った分を守るように動きます。

- 電波が途切れても、つながり直せば同じファイルに続けて録ります。
- ファイルは 30 分ごとに分かれるので、万一ファイルが壊れても失うのはその分だけです。
- 電池が切れそうになると、ファイルを閉じてから自分で電源を切ります。
- 画面を消している間は、触れても反応しません。バッグの中などで、うっかり録音が止まる心配がありません。
- 電源の入り・切りと、録音の開始・終了で違う音が鳴るので、画面を見なくても押せたことが分かります。

## こんなときは

メニューは、下の真ん中のボタンで開きます。項目が多いときは、指で上下になぞってください。

### つなぐ

- **電源を入れるだけでつながってほしい** → メニューの「起動時に再接続」をオン（初期値はオン）
- **つながらない** → Core2 の「BT接続」を押すか、B+COM の B2 ボタンを短く押す
- **別のインカムにつなぎたい・登録を消したい** → メニューの「機器を探す」
- **ログに「〜側にペアリングキーが無いようです。」と出た** → B+COM の側でペアリングの記録が消えています（初期化した、別の機器を登録したなど）。「機器を探す」からペアリングし直す
- **声が届かない** → メニューの「音声接続」を一度オフにして、オンに戻す

### 声を合わせる

- **自分の声がどう録れるか、耳で確かめたい** → メニューの「ループバックモニター」をオン。少し遅れて、自分の声がヘルメットに返ってきます（録音を始めると止まります）
- **マイクの音量を変えたい** → B+COM のスマホアプリで変える。メニューの「マイク感度」は、Core2 から感度を変えられるインカムでだけ使えます（B+COM SB6XR は対応していません）

### 録る

- **ファイルを短く分けたい・1 つにまとめたい** → メニューの「ファイル分割」で長さを選ぶ（分割なし〜1 時間。録音中は変えられません）
- **録音中に電源を切りたい** → 電源ボタンを長押し。ファイルを閉じてから切れます
- **SD カードを替えたい** → 録音を止めてから抜く。電源は入れたままで構いません。挿し直すと、数秒で使えるようになります
- **ファイル名の日時がずれている** → SD カードの一番上に `settime.txt` を置き、`2026-11-20 10:30:00` の形で日本時間を書いて電源を入れる。読み込むと、名前が `settime.done` に変わります

### 電池・画面

- **電池でどのくらい録れるか** → 初期型の Core2（390mAh の電池、使い込んだもの）で、画面を消して約 2 時間 40 分録れました。電池の残量の % は、録れる残り時間に合わせてほぼ均等に減ります
- **電池を長持ちさせたい** → 電源ボタンを短く押して画面を消す（点けたままより 2 割ほど長く録れます）。メニューの「画面の明るさ」を下げる
- **日なたで画面が見にくい** → メニューの「画面の明るさ」を上げる

### 困ったとき

- **何が起きたか知りたい・不具合を報告したい** → メニューの「ログ表示」で見る。「ログを SD に保存」がオン（初期値）なら、SD カードの `LOG` フォルダにも残っていて、PC で読めます
- **最初からやり直したい** → メニューの「設定の初期化」。録音したファイルは消えません。初期化のあとは、ペアリングし直してください

## 知っておいてほしいこと

- 録れるのは、B+COM がまとめた会話の音声 1 本（モノラル）です。話している人ごとに分けたり、ステレオにしたりはできません。
- 電波が途切れていた間は、その時間を詰めて記録します。動画と合わせるときは、途切れたところから後ろがずれます。
- 録音中に SD カードを抜くと、そのファイルの最後の数秒が失われます。書き込みのちょうど途中だと、カードの記録が傷んで、ほかのファイルが読めなくなることもあります。抜くのは録音を止めてからにしてください。
- B+COM で確かめたのは、SB6XR V1.3 との接続と音声の受信です。アクションカメラ録音に対応したほかの機種（SX1・ONE・SB6X）では、確かめていません。
