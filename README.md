# m5-intercom-recorder

B+COM などの バイク用 インカムの会話を、M5Stack Core2 で microSD カードに録音するレコーダーです。 

- スマホを使わずにインカムの会話を録音できます。
- 長いツーリングでも丸ごと録れます（1 時間で約 115MB。32GB のカードで約 270 時間）。
- WAV で保存するので、動画編集ソフトにそのまま読み込めます。
- レベルメーターで自分や参加者の声の録音レベルを確認できます。

B+COM の「アクションカメラ録音」を Insta360 や GoPro の代わりに M5Stack Core2 でできるようにしたものです。

## 必要なもの

- M5Stack Core2 ( V1.0確認済 )
- microSD カード（32GB 以下ならそのまま使えます。64GB 以上は、メニューの「SDカード初期化」で初期化してから使います）
- B+COM（ SB6XR V1.3 テスト済 ）
- 長く走る場合は USB Type C 充電器（ 内蔵電池で 2〜3 時間ほどとれます）

## 書き込み

### ダウンロードと書き込み

1. [リリース](https://github.com/daig0rian/m5-intercom-recorder/releases)から `m5-intercom-recorder-vX.Y.Z.bin` をダウンロードします。
2. M5Stack Core2 を USB で PC につなぎ、Chrome か Edge で [ESP Launchpad](https://espressif.github.io/esp-launchpad/) を開きます。
3. 「DIY」で、ダウンロードしたファイルを Flash Address `0x0` に書き込みます。

バージョンアップするときは、`-update.bin` で終わるファイルを  Flash Address `0x10000` に書き込むと、設定とペアリングが残ります


## 使い方

### はじめに一度だけ: B+COM とペアリングする

1. B+COM を起動後、 B2 ボタンを長押しして、ペアリング待機状態にします。B+COM から「B+COM2 ペアリング」と聞こえます。
2. M5Stack Core2 の電源を入れ「機器検索」を押すと機器がリストされるので　B+COM の行を押します。（SB6XR は「B6R Universal」と表示されました）
3. B+COM から「B+COM2接続 ポポポポポ」と聞こえたら完了です。どちらも電源を切ってOK。

### ツーリングの日

1. B+LINK で、二人の通話をつなぎます。
2. M5Stack Core2 の電源を入れると、最後につないだ B+COM に自動的に接続されます。B+COM から「B+COM2接続 ポポポポポ」と聞こえます。
3. ペアツーリングのときは、お互いの声が大体同じレベルで入力されているかをレベルメーターの振れ方で確認します。（3人以上いれば音量差に気づけますが2人だと気づけないため）
4. 「録音」を押して出発します。電源ボタンを短く押すと画面が消えて電池が長持ちしまするほか、画面タッチの誤動作も防げます。
5. 着いたら「停止」を押します。

M5Stack Core2 を持つ人は、列の先頭か最後尾を走ると通信が安定します（B+COM のアクションカメラ録音と同じおすすめです）。


### 帰ってから

SD カードの `REC` フォルダに、録音した日時の名前（`20261120_103000.wav` など）で保存されています。
WAV なので、PC でそのまま再生でき、動画編集ソフトにもそのまま読み込めます。

### カメラの映像と合わせる

インカム音声をカメラ映像に合わせて編集することを考えている場合は、出発前に同期映像を収録しておくと便利です。

1. 録音を始めたら、メニューの「映像同期」を開きます。
2. M5Stack Core2 をインカムのマイクの近くに持ち、画面をカメラに写します。
3. 15 秒程度カメラに移します。入れ替わるところが 1 回写れば十分です。
3. 編集では、映像をコマ送りして四角の白と黒が入れ替わるコマを探し、そこに録音の「ポーン」の鳴り始めを重ねます。

## 安心して録音するための機能について

運転を邪魔せず録音するための機能がいくつかあります。

- インカムとの接続が途切れても録音は止まりません。Bluetooth が切れたときは自動的に再接続して続きを録音します。接続が切れていた部分は無音で収録されます。
- ファイルはデフォルトで 30 分ごとに分けられます。万一ファイルが壊れても録音全体を壊さないためです。。
- 電池が切れそうになると、ファイルを閉じてから自分で電源を切ります。
- 画面を消している間は、触れても反応しません。バッグの中などで、うっかり録音が止まる心配がありません。
- 電源の入り・切りと、録音の開始・終了で違う音が鳴るので、画面を見なくても押せたことが分かります。

## こんなときは

メニューは、下の真ん中のボタンで開きます。項目が多いときは、指で上下になぞってください。

### つなぐ

- **電源を入れるだけでつながってほしい** → メニューの「起動時に再接続」をオン（初期値はオン）
- **つながらない** → M5Stack Core2 の「BT接続」を押すか、B+COM の B2 ボタンを短く押す
- **録音中に切れたあとの、Core2 からのつなぎ直しをやめたい** → 画面に「つなぎ直し中…」と出ている間に「BT切断」を押す。やめたあとも録音は続き、B+COM の B2 ボタンでつなげば、そのまま続きを録ります
- **別のインカムにつなぎたい・登録を消したい** → メニューの「機器を探す」
- **ログに「〜側にペアリングキーが無いようです。」と出た** → インカムの側でペアリングの記録が消えています（初期化した、別の機器を登録したなど）。「機器を探す」からペアリングし直す
- **声が届かない** → メニューの「音声接続」を一度オフにして、オンに戻す。

### 声を合わせる

- **声がどう録れるか、耳で確かめたい** → メニューの「ループバックモニター」をオン。少し遅れて、声がヘルメットに返ってきます（録音を始めると止まります）
- **マイクの音量を変えたい** → B+COM のスマホアプリで変える。メニューの「マイク感度」は、Core2 から感度を変えられるインカムでだけ使えます（B+COM SB6XR は対応していません）

### 録る

- **ファイルを短く分けたい・1 つにまとめたい** → メニューの「ファイル分割」で長さを選ぶ（分割なし〜1 時間。録音中は変えられません）。分割なしでも、1 ファイルが約 4GB（約 34 時間）になると分けます
- **「SDカードが読めません」と出る・64GB 以上のカードを使いたい** → メニューの「SDカード初期化」を押し、右のボタンが赤い「初期化する?」に変わったら、3 秒以内にもう一度押す。カードの中身はすべて消えます。大きいカードでは時間がかかり、その間は画面が止まります
- **録音中に電源を切りたい** → 電源ボタンを長押し。ファイルを閉じてから切れます
- **SD カードを替えたい** → 録音を止めてから抜く。電源は入れたままで構いません。挿し直すと、数秒で使えるようになります
- **ファイル名の日時がずれている** → SD カードの直下に `settime.txt` を置き、`2026-11-20 10:30:00` の形で日本時間を書いて電源を入れる。読み込むと、名前が `settime.done` に変わります

### 電池・画面

- **電池でどのくらい録れるか** → 初期型の Core2（390mAh の電池、使い込んだもの）で、満充電から画面を消して約 3 時間録れました。電池の残量の % は、録れる残り時間に合わせてほぼ均等に減ります
- **電池を長持ちさせたい** → 電源ボタンを短く押して画面を消す（点けたままより 2 割ほど長く録れます）。メニューの「画面の明るさ」を下げる
- **日なたで画面が見にくい** → メニューの「画面の明るさ」を上げる

### 困ったとき

- **何が起きたか知りたい・不具合を報告したい** → メニューの「ログ表示」で見る。「ログを SD に保存」がオン（初期値）なら、SD カードの `LOG` フォルダにも残っていて、PC で読めます
- **最初からやり直したい** → メニューの「設定の初期化」。録音したファイルは消えません。初期化のあとは、ペアリングし直してください

## 音質

録音される音の音質は、インカムとの Bluetooth の区間で何が使われるかで決まります。ファイルには、届いた音を圧縮せずにそのまま保存します。

| | チャンネル | サンプリング周波数 | コーデック | ビットレート |
|---|---|---|---|---|
| Bluetooth (mSBC) | モノラル | 16 kHz | mSBC | 61kbps |
| Bluetooth (CVSD) | モノラル | 8 kHz | CVSD | 64kbps |
| ファイル保存 | モノラル | 届いたまま（16 kHz か 8 kHz） | WAV（16 ビット PCM） | 256kbps（8 kHz のときは 128kbps） |

最高の音質の時には画面の上に「音声 mSBC 16kHz」と表示されます。


## ご注意

- 録れるのは、B+COM がまとめた会話の音声 1 本（モノラル）です。話している人ごとに分けたり、ステレオにしたりはできません。
- 録音中に SD カードを抜くと、そのファイルの最後の数秒が失われます。書き込みのちょうど途中だと、カードの記録が傷んで、ほかのファイルが読めなくなることもあります。抜くのは録音を止めてからにしてください。
- B+COM で確かめたのは、SB6XR V1.3 との接続と音声の受信です。アクションカメラ録音に対応したほかの機種（SX1・ONE・SB6X）では、確かめていません。


### ビルド方法

ESP-IDF v5.5 系（v5.5.6 で確認）でビルドして、Core2 に書き込みます。

```
idf.py build
idf.py -p PORT flash
```

`PORT` は Core2 をつないだシリアルポートです（Windows なら `COM3` など）。必要な部品はビルドのときに自動で取得されます。
